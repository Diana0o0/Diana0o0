# 高级财务助手

这是一个轻量级的命令行工具，用于从发票或收据文本中提取关键信息并生成中文 Markdown 汇总表，同时按货币自动汇总金额。它适合将 OCR 或其他文本化的票据内容快速整理为结构化数据，并支持在多次输入之间保持状态。

## 功能特点
- **自动分单据**：可根据空行或自定义分隔符拆分文档，便于处理一次包含多张单据的文本。
- **关键信息提取**：尝试识别日期、城市、简述、金额和货币，缺失字段以`缺失`标注，金额统一保留两位小数。
- **连续汇总**：可加载/保存状态文件，在多次执行间持续追加新数据，并支持按输入顺序或日期排序。
- **Markdown 输出**：生成`日期 | 城市 | 简述 | 金额 | 货币`列顺序的表格，并提供按货币的总计概览。

## 快速开始
1. 准备包含发票文本的文件，多个单据可使用空行或`---`分隔。
2. 运行命令：

   ```bash
   python invoice_assistant.py --files doc1.txt doc2.txt --state invoices.json --order date
   ```

3. 查看终端输出的 Markdown 表格与按货币汇总；`invoices.json`会保存累计结果供下次追加。

## CLI 选项
- `--files FILE [FILE ...]`：要处理的文本文件路径，按给定顺序解析。
- `--text "原始文本"`：直接传入一段包含单据的文本（可与文件同时使用）。
- `--delimiter "---"`：自定义单据分隔符（默认使用空行或`---`）。
- `--state PATH`：状态文件路径；若存在则先加载历史记录，处理后会写回。
- `--order {input,date}`：汇总表顺序，`input`按追加顺序，`date`按日期先后（无法解析日期的记录保持原序）。

## 示例输入
```
日期: 2024-05-10
城市: 上海
项目: 市场调研差旅
金额: ￥2350.5
---
2024年6月2日 深圳
备注: 客户拜访交通
金额: USD 120
```

示例命令：

```bash
python invoice_assistant.py --text "$(cat sample.txt)" --order date
```

## 输出示例
```
| 日期 | 城市 | 简述 | 金额 | 货币 |
| --- | --- | --- | --- | --- |
| 2024-05-10 | 上海 | 市场调研差旅 | 2350.50 | CNY |
| 2024-06-02 | 深圳 | 客户拜访交通 | 120.00 | USD |

按货币汇总：
- CNY: 2350.50
- USD: 120.00
```
